# NeighborhoodExplorer 新手操作指南（Windows）

本指南面向已经拿到或部署好 NeighborhoodExplorer、但不熟悉命令行的用户。跟着步骤操作即可生成基因邻域 TSV 表格和 HTML 可视化图；不需要修改 Python 源代码。

> 本指南中的命令适用于 Windows PowerShell。命令里的示例文件名、基因名和目录可以换成你自己的值。

## 开始前准备

你需要准备：

1. 已下载或部署好的 `NeighborhoodExplorer` 项目文件夹。
2. 一个**带注释的 GenBank 文件**，通常扩展名为 `.gbk`、`.gb` 或 `.gbff`。
3. 目标基因的 `locus_tag` 或 `gene` 名称。
4. Windows PowerShell，以及 Python 3.10 或更高版本。

注意：只有 DNA 序列、没有基因注释的 FASTA 文件（例如 `.fasta` 或 `.fa`）不能直接用于本工具。输入文件需要包含 GenBank 格式的 CDS 注释。

## 第一步：找到项目文件夹并打开 PowerShell

在文件资源管理器中找到项目文件夹。文件夹内应能看到 `README.md`、`requirements.txt` 和 `neighborhood_explorer` 子文件夹。

在该文件夹的空白处按住 **Shift** 并点击鼠标右键，选择“在此处打开 PowerShell 窗口”或“在终端中打开”。如果菜单里没有此选项，也可以：

1. 从开始菜单打开 **Windows PowerShell**。
2. 输入 `cd `（注意 `cd` 后有空格）。
3. 把项目文件夹拖进 PowerShell 窗口，路径会自动填入。
4. 按 Enter。

例如，如果项目在 `G:\Programming\PythonPrograms\NeighborhoodExplorer`：

```powershell
cd "G:\Programming\PythonPrograms\NeighborhoodExplorer"
```

确认当前目录正确：

```powershell
Get-ChildItem
```

输出中应能看到 `requirements.txt` 和 `neighborhood_explorer`。

## 第二步：确认 Python 和依赖可用

检查 Python 版本：

```powershell
python --version
```

版本需要是 Python 3.10 或更高。如果 PowerShell 提示找不到 `python`，请先安装 Python，并在安装时启用 **Add Python to PATH**；也可以尝试：

```powershell
py --version
```

检查项目依赖：

```powershell
python -c "import Bio, plotly; print('依赖检查通过')"
```

如果看到“依赖检查通过”，可以继续下一步。如果报 `ModuleNotFoundError`，请在项目根目录安装依赖：

```powershell
python -m pip install -r requirements.txt
```

然后重新运行依赖检查命令。

## 第三步：准备 GenBank 输入文件

如果已经有 `.gbk`、`.gb` 或 `.gbff` 文件，请记下它的完整路径。建议在项目目录下建立一个专门放输入文件的文件夹：

```powershell
New-Item -ItemType Directory -Force input
```

把 GenBank 文件复制到该文件夹，例如：

```text
NeighborhoodExplorer\
├── input\
│   └── genome.gbk
├── neighborhood_explorer\
├── requirements.txt
└── README.md
```

如果还没有 GenBank 文件，可以从 NCBI 等数据库下载目标序列的**带注释 GenBank 格式**文件。不要选择 FASTA 格式；具体下载页面和选项可能随数据库界面变化。

## 第四步：找到目标基因名称

程序使用 CDS 特征中的 `locus_tag` 或 `gene` 值查找目标，不会按基因描述、蛋白质名称或 DNA 序列进行搜索。

1. 用文本编辑器（例如 VS Code 或 Notepad）打开 `.gbk` 文件。
2. 搜索 `/locus_tag=` 或 `/gene=`。
3. 在 CDS 注释附近找到目标基因对应的值。例如：

```text
     CDS             1234..2345
                     /locus_tag="ABC_0001"
                     /gene="example"
```

可以将 `ABC_0001` 或 `example` 作为 `--target` 的值。请准确复制引号内的内容，不要复制引号本身。匹配区分大小写；如果名称在文件中出现多次，程序会提示警告并使用第一个匹配的 CDS。

## 第五步：运行程序

确保 PowerShell 当前目录仍是项目根目录。以下命令使用 `input\genome.gbk` 作为输入文件，并提取目标基因上下游各 5 个 CDS：

```powershell
python -m neighborhood_explorer -i ".\input\genome.gbk" -t "ABC_0001" -n 5 -o ".\results\neighborhood"
```

运行前请根据实际情况替换：

- `.\input\genome.gbk`：你的 GenBank 文件路径。
- `ABC_0001`：你在上一步找到的 `locus_tag` 或 `gene`。
- `5`：目标基因上游和下游分别提取的 CDS 数量。
- `.\results\neighborhood`：输出文件前缀；无需添加 `.tsv` 或 `.html`。

例如，以 `gene` 名称搜索并且每侧取 3 个基因：

```powershell
python -m neighborhood_explorer --input ".\input\genome.gbk" --target "example" --num 3 --output ".\results\example"
```

如果只想输出目标 CDS 本身，将 `-n` 设为 `0`：

```powershell
python -m neighborhood_explorer -i ".\input\genome.gbk" -t "ABC_0001" -n 0 -o ".\results\target_only"
```

查看参数帮助：

```powershell
python -m neighborhood_explorer --help
```

## 第六步：查看结果

成功时，PowerShell 会显示提取的基因数和两个输出文件路径。默认输出示例：

```text
results\
├── neighborhood.tsv
└── neighborhood.html
```

- **`neighborhood.html`**：双击即可在浏览器中打开交互式基因邻域图。目标基因以红色高亮；悬停在箭头上可查看基因名、坐标、链方向和长度。HTML 内嵌绘图库，打开图表时不需要联网。
- **`neighborhood.tsv`**：制表符分隔的数据表，可用 Excel、LibreOffice 或文本编辑器打开。列为 `Gene_Name`、`Start`、`End`、`Strand`、`Length`。坐标采用从 1 开始的闭区间；`+` 是正链，`-` 是负链，`?` 表示链方向未知。

默认情况下，输出目录会自动创建。再次使用相同前缀运行会覆盖对应的 TSV 和 HTML 文件；如需保留旧结果，请换一个输出前缀。

## 常见问题

### `No module named neighborhood_explorer`

PowerShell 当前目录可能不在项目根目录。运行：

```powershell
Get-Location
Get-ChildItem
```

确认当前目录下同时能看到 `requirements.txt` 和 `neighborhood_explorer` 文件夹，然后再运行命令。

### 提示找不到输入文件

检查 `-i` 后面的路径是否正确。相对路径以当前 PowerShell 目录为起点；也可以使用绝对路径，例如：

```powershell
python -m neighborhood_explorer -i "D:\data\genome.gbk" -t "ABC_0001"
```

### 提示找不到目标基因

确认目标值来自该文件的 CDS 注释中的 `/locus_tag=` 或 `/gene=`，并检查大小写、拼写和引号是否正确。程序只查找 CDS 特征，不会查找其他类型的注释。

### 只提取到少量邻域基因

`-n 5` 表示目标两侧分别最多取 5 个 CDS。目标靠近序列记录开头或结尾时，可用基因可能少于 5 个；邻域不会跨越不同 contig 或 GenBank 记录。

### 输入文件无法解析

请确认下载的是 GenBank 格式的注释文件，而不是 FASTA 序列文件，并检查文件是否完整、扩展名是否与文件内容相符。

### PowerShell 命令运行后没有生成结果

检查是否显示错误信息。如果程序报告成功，记下它打印的输出路径，并通过文件资源管理器打开该位置。输出路径相对于当前 PowerShell 目录。
